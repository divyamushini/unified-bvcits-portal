# BVCITS Digital Campus Portal

A modern digital campus platform for **BVCITS**, providing easy access to college information and services for students, faculty, parents, and other stakeholders.

### ✨ Features

* 🏫 College Information & Campus Gallery
* 👨‍🎓 Student, Faculty & Parent Portals
* 📝 Registration & Login
* 📢 Notices & Placements
* 🔬 Research & College Services
* 📞 Contact Information

### 🛠️ Tech Stack

**React • TypeScript • Vite • CSS**

### 🚀 Run Locally

```bash
npm install
npm run dev
```

Developed for **BVCITS** as an academic project.
